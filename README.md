# AgroLeak Landing Page

Landing page académica del proyecto **AgroLeak** para el curso de IoT de la UPC.

## Estructura

```text
Landing-page-AgroLeak/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   │   └── agroleak-logo.png
│   └── reference/
│       └── agroleak-visual-style-guide.png
└── README.md
```

## Uso

Abre `index.html` en el navegador o publica la rama `main` con GitHub Pages desde `/ (root)`.

## Nota sobre fotografías

Las fotografías reales de campo usadas en la landing se cargan desde fuentes externas (Unsplash y Wikimedia Commons). El logo y la guía visual del proyecto sí se encuentran dentro de `assets/`.

## Proyecto

AgroLeak combina monitoreo de caudal, evidencia visual para señales de plagas y actuación segura mediante una válvula con retroalimentación.
